# GenAI Bots 🚀

A collection of Generative AI applications and experiments built using LangChain, Google Gemini, Groq, Ollama, and AI Agents.

## Features

- Question Answering Bot
- Google Search Agent
- Prompt Chaining
- Memory in LangChain
- Structured Output Generation
- Ollama Integration
- Groq Integration
- AI Agents
- Google Search Powered Agent
